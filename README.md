# QR Code Generator

A responsive and user-friendly QR Code Generator built with **HTML**, **CSS**, and **JavaScript**. This application allows users to generate QR codes instantly, download them as images, and maintain a local history of previously generated QR codes using the browser's Local Storage.

## 🌐 Live Demo

**Live Website:** https://syedabsar99.github.io/qr-code-generator/

## 📸 Preview

![QR Code Generator Screenshot](./screenshot.png)

## ✨ Features

* Generate QR codes instantly from text or URLs
* Download generated QR codes as PNG images
* Automatically stores generated QR codes in Local Storage
* View previously generated QR codes from the history section
* Reuse QR codes directly from history
* Delete individual history items
* Clear the entire history
* Responsive design for desktop and mobile devices
* Clean and modern user interface

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)
* QR Code API

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/syedabsar99/qr-code-generator.git
```

2. Open the project folder.

3. Open `index.html` in your browser or use the VS Code Live Server extension.
